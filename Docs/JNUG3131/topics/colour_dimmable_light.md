# Colour Dimmable Light

The Colour Dimmable Light device is a multi-colour light that can have its hue, saturation and luminance varied, and can be switched on and off.

-   The Device ID is 0x0102.

-   The header file for the device is **colour\_dimmable\_light.h**.

-   The clusters supported by the device are listed in [Section 3.3.1](supported_clusters_006.md#ID_9AD8AA49-584A-4224-A664-5F472F8E372D).

-   The device structure, `tsZLO_ColourDimmableLightDevice`, is listed in [Section 3.3.2](device_structure_001.md#ID_E069EFB9-2590-4E51-B17C-DF11FFDE1691).

-   The endpoint registration function for the device, **eZLO\_RegisterColourDimmableLightEndPoint\(\)**, is detailed in [Section 3.3.3](registration_function_004.md#ID_822F264C-2C44-4E6F-8A48-A10F34220BD0).
