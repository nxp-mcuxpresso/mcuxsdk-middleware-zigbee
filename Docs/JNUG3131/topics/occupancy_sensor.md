# Occupancy Sensor

The Occupancy Sensor device reports the presence \(or not\) of occupants in an area.

-   The Device ID is 0x0107.

-   The header file for the device is **occupancy\_sensor.h**.

-   The clusters supported by the device are listed in [Section 3.8.1](supported_clusters_001.md#ID_874DF444-F6F5-4116-A671-6216FEF4A57A).

-   The device structure, `tsZLO_OccupancySensorDevice`, is listed in [Section 3.7.2](device_structure_018.md#ID_71703D92-BA9C-4D6A-B5AC-F602FC6774E3).

-   The endpoint registration function for the device, **eZLO\_RegisterOccupancySensorEndPoint\(\)**, is detailed in [Section 3.7.3](registration_function_006.md#ID_B25549C8-D59D-4559-ACB1-C04E56171CE5).
