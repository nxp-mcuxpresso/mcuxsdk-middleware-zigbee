# Extended Colour Light

The Extended Colour Light device is typically used in nodes that contain a colour lamp with adjustable colour and brightness. This device supports a range of colour parameters, including hue/saturation, enhanced hue, colour temperature, colour loop, and XY.

-   The Device ID is 0x010D.

-   The header file for the device is **extended\_colour\_light.h**.

-   The clusters supported by the device are listed in [Section 3.14.1](supported_clusters_009.md#ID_68BEB403-E9E7-485D-80AA-7BC20F58A107).

-   The device structure, `tsZLO_ExtendedColourLightDevice`, is listed in [Section 3.14.2](device_structure_006.md#ID_26263C1E-D8AA-4D05-A38E-B47A1CB3F199).

-   The endpoint registration function for the device, **eZLO\_RegisterExtendedColourLightEndPoint\(\)**, is detailed in [Section 3.14.3](registration_function_010.md#ID_C2D702EC-0F1C-405A-9E47-B1FA15431D8E).
