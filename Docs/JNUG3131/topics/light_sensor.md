# Light Sensor

The Light Sensor device reports the illumination level in an area.

-   The Device ID is 0x0106.

-   The header file for the device is **light\_sensor.h**.

-   The clusters supported by the device are listed in [Section 3.7.1](supported_clusters_018.md#ID_DE475C16-3FED-4B3C-86A9-A14667A3EF16).

-   The device structure, `tsZLO_LightSensorDevice`, is listed in [Section 3.7.2](device_structure_018.md#ID_71703D92-BA9C-4D6A-B5AC-F602FC6774E3).

-   The endpoint registration function for the device, **eZLO\_RegisterLightSensorEndPoint\(\)**, is detailed in [Section 3.7.3](registration_function_006.md#ID_B25549C8-D59D-4559-ACB1-C04E56171CE5).
