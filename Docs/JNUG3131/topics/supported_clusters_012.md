|

| ------------------------------------------- | -------------------- |
| Server (Input) side                         | Client (Output) side |
| **Mandatory**                                   |                      |
| Basic                                       |                      |
| Identify                                    |                      |
| Groups                                      |                      |
| Scenes                                      |                      |
| On/Off                                      |                      |
| **Optional**                                    |                      |

|

The mandatory attributes within each cluster for this device type are indicated in the *ZigBee Lighting and Occupancy Device Specification \(15-0014-01\)*.
