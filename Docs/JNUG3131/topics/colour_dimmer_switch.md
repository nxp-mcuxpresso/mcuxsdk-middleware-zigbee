# Colour Dimmer Switch

The Colour Dimmer Switch device controls the hue, saturation and luminance of a multi-colour light, and to switch the light device on and off.

-   The Device ID is 0x0105.

-   The header file for the device is **colour\_dimmer\_switch.h**.

-   The clusters supported by the device are listed in [Section 3.6.1](supported_clusters_017.md#ID_12E5C30B-C0E5-48B4-9CE6-8002BFD65073).

-   The device structure, `tsZLO_ColourDimmerSwitchDevice`, is listed in [Section 3.6.2](device_structure_002.md#ID_A165B848-6659-415F-9FDD-CB4EA6DA38B8).

-   The endpoint registration function for the device, **eZLO\_RegisterColourDimmerSwitchEndPoint\(\)**, is detailed in [Section 3.6.3](registration_function_015.md#ID_B837D18D-FE25-4E17-AE59-3EA9C7B04D1A).
