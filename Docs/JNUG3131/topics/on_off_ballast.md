# On/Off Ballast

The On/Off Ballast is a lighting device that can be switched on/off from a controller device, such as an On/Off Light Switch or an Occupancy Sensor.

-   The Device ID is 0x0108.

-   The header file for the device is **on\_off\_ballast.h**.

-   The clusters supported by the device are listed in [Section 3.9.1](supported_clusters_004.md#ID_CF7A94C5-1664-4256-9FB5-2AACAF464360).

-   The device structure, `tsZLO_OnOffBallastDevice`, is listed in [Section 3.9.2](device_structure_014.md#ID_7378563B-EC9E-4B87-988F-FF8053647E49).

-   The endpoint registration function for the device, **eZLO\_RegisterOnOffBallastEndPoint\(\)**, is detailed in [Section 3.9.3](registration_function_017.md#ID_C7D9E9A3-5AE2-42EB-B82B-C5AC0D37A2B5).
