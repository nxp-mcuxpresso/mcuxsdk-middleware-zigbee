The following structure contains the enumerations used to identify the server attributes of the Fan Control cluster.

typedef enum 
{

    E_CLD_FAN_CONTROL_ATTR_ID_FAN_MODE_SEQUENCE,               
} teCLD_FanControl_AttributeID;
