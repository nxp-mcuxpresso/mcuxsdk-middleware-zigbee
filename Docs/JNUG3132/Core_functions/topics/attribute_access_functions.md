# Attribute Access Functions

The following functions are provided in the ZCL for accessing cluster attributes on a remote device:

1.  [eZCL\_SendReadAttributesRequest](ezcl_sendreadattributesrequest.md#id_21e5affd-30b3-4e8f-85bf-bc9a2f27804e)
2.  [eZCL\_SendWriteAttributesRequest](ezcl_sendwriteattributesrequest.md#id_ad6e1ea7-94bd-4bd1-8c23-cde42f86dc05)
3.  [eZCL\_SendWriteAttributesNoResponseRequest](ezcl_sendwriteattributesnoresponserequest.md#id_3e0fbfbd-2051-405e-9c89-09a19af9be82)
4.  [eZCL\_SendWriteAttributesUndividedRequest](ezcl_sendwriteattributesundividedrequest.md#id_3e36cf5f-e443-4283-b12b-9801f4e3bde4)
5.  [eZCL\_SendDiscoverAttributesRequest](ezcl_senddiscoverattributesrequest.md#id_29cecd4f-b428-49c1-a062-1023d9ae37fc)
6.  [eZCL\_SendDiscoverAttributesExtendedRequest](ezcl_senddiscoverattributesextendedrequest.md#id_a0915529-7638-4d09-bab8-4b817da214ce)
7.  [eZCL\_SendConfigureReportingCommand](ezcl_sendconfigurereportingcommand.md#id_7c891078-1d5e-485d-b271-259810c0bbe7)
8.  [eZCL\_SendReadReportingConfigurationCommand](ezcl_sendreadreportingconfigurationcommand.md#id_91f7d818-37d1-4f5b-9a49-1fc5741648ca)
9.  [eZCL\_ReportAllAttributes](ezcl_reportallattributes.md#id_460113f4-46a5-4661-8ab3-370a1f247cfd)
10. [eZCL\_ReportAttribute](ezcl_reportattribute.md#id_74e58772-71b3-4d19-a33a-a4bbaa5234d1)
11. [eZCL\_CreateLocalReport](ezcl_createlocalreport.md#id_9a29eda5-2e40-4c22-9373-960094d7c050)
12. [eZCL\_SetReportableFlag](ezcl_setreportableflag.md#id_5c5e9c88-a018-4790-9457-f8f0ace9fd45)
13. [vZCL\_SetDefaultReporting](vzcl_setdefaultreporting.md#id_704abde9-d352-428e-8cf1-1883d682f552)
14. [eZCL\_HandleReadAttributesResponse](ezcl_handlereadattributesresponse.md#id_2fa096dd-9637-46ea-84f0-8b187a4acc13)
15. [eZCL\_ReadLocalAttributeValue](ezcl_readlocalattributevalue.md#id_c2334021-9971-4b74-8186-07299aba3c82)
16. [eZCL\_WriteLocalAttributeValue](ezcl_writelocalattributevalue.md#id_36646193-e336-4498-adbb-5c5ded56c5bf)
17. [eZCL\_OverrideClusterControlFlags](ezcl_overrideclustercontrolflags.md#id_ecb17854-2ae8-4716-9f82-713039bdf42c)
18. [eZCL\_SetSupportedSecurity](ezcl_setsupportedsecurity.md#id_4c6f345d-e60b-4e02-88d5-f0288c01353b)

**Note:** In addition to the general function **eZCL\_SendReadAttributesRequest\(\)**, there are cluster-specific ‘read attributes’ functions for some clusters.
