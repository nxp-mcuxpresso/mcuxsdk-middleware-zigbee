# Removing a power profile entry

The server application can remove a power profile from the device by calling the function **eCLD\_PPRemovePowerProfileEntry\(\)** to delete the corresponding entry of the local power profile table. The entry to be deleted is specified by means of the relevant Power Profile ID.
