# Obtaining a Power Profile Entry

The server application can obtain the details of a power profile supported by the server by reading the corresponding entry of the power profile table using the function **eCLD\_PPGetPowerProfileEntry\(\)**. The required entry is specified by means of the relevant Power Profile ID.
