# Notification of Energy Phases in Power Profile Schedule \(by Server\)

The server application can use the function **eCLD\_PPEnergyPhasesScheduleStateNotificationSend\(\)** to send an unsolicited Energy Phases Schedule State Notification to a cluster client, in order to inform the client of the energy phases that are in the schedule of a particular power profile.
