# Appendix B.3: Configuring attribute reporting

If attribute reporting is to be used by a cluster then the feature must be enabled at compile-time, as detailed in [Appendix B.3.1](compile-time_options.md#id_84f10234-23ce-42f7-a567-f5415e76352a). Then:

-   If automatic attribute reporting is to be implemented then the reports must be configured as described in [Appendix B.3.5](configuring_automatic_attribute_reports_from_clien.md#id_a5332bea-91c9-42be-aa55-63eb5b644490).

-   If default reporting is to be implemented then the reports must be configured as described in [Appendix B.3.6](configuring_default_reporting_on_server.md#id_0ee5c3fa-71ff-4e90-8062-e0a7201c793e).


The ZCL configuration for attribute reporting is described in [Appendix B.3.7](zcl_configuration_for_attribute_reporting.md#id_dbc32ec9-5df8-41f1-ba42-e6f373ed2a88) for users who wish to modify this configuration.
