# Last Stack Error

The last error generated by the ZigBee PRO stack can be obtained using the ZCL function **eZCL\_GetLastZpsError\(\)**, described in [Section 5.1](../../Core_functions/topics/general_functions_.md#id_1f0df55c-1a42-4a30-9031-deb3d5393ead). The possible returned errors are listed in the Return/Status Codes chapter of the *ZigBee 3.0 Stack User Guide \(JNUG3130\)*.
