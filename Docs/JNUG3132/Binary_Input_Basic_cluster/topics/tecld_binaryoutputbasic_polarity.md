# teCLD\_BinaryOutputBasic\_Polarity

The following structure contains the enumerations used to specify the value of the `u8Polarity` attribute \(see [Section 19.4.2](binary_output_basic_structure_and_attributes.md#id_02215436-44b7-465f-a8f9-ffd02c25195d)\).

```
typedef enum 
{ 
    E_CLD_BINARY_OUTPUT_BASIC_POLARITY_NORMAL,
    E_CLD_BINARY_OUTPUT_BASIC_POLARITY_REVERSE
}teCLD_BinaryOutputBasic_Polarity

```
