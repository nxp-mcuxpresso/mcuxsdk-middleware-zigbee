# teCLD\_BinaryInputBasic\_Polarity

The following structure contains the enumerations used to specify the value of the `u8Polarity` attribute \(see [Section 19.3.2](binary_input_basic_structure_and_attributes.md#id_80036992-711c-42db-94e2-41bdfde72c66)\).

```
typedef enum 
{ 
   E_CLD_ BINARY_INPUT_BASIC_POLARITY_NORMAL                        ,
   E_CLD_ BINARY_INPUT_BASIC_POLARITY_REVERSE
}teCLD_BinaryInputBasic_Polarity

```
