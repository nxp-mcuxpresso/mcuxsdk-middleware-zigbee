# LCE Contents

The information contained in an LCE includes:

-   LCE ID \(provided by utility company\)

-   Target device class and enrolment group

-   Start-time

-   Duration

-   Criticality level

-   Required adjustment\(s\)

-   Randomization requirements \(for start-time and end-time\)


For a full list and description of the LCE data, refer to the description of the LCE structure `tsSE_DRLCLoadControlEvent` in [Section 41.11.1](tsse_drlcloadcontrolevent.md#id_beb5b077-259a-4c2d-a863-11cc8d38d3e1).
