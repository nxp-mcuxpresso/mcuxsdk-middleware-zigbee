# Table and Parameters

The IAS ACE cluster server hosts the following table and sets of parameters:

-   **Zone table:** The Zone table contains an entry for each enrolled zone. Each entry stores the identifier and type of the zone, as well as the IEEE/MAC address of the device which hosts the zone \(see [Section 38.7.2](zone_table_entry.md#id_917bf1dd-14fe-4c05-87cf-cc071f948c45)\).

-   **Zone parameters:** This set of parameters contains certain zone properties including the zone status, the zone name/label and the zone arm/disarm code \(see [Section 38.7.3](zone_parameters.md#id_555011fc-2e63-4ba8-8f3a-98f719b35b31)\)

-   **Panel parameters:** This set of parameters contains certain status information about the display panel and alarm \(see [Section 38.7.4](panel_parameters.md#id_404b2665-5072-489a-a49d-24efc8eca54a)\).
