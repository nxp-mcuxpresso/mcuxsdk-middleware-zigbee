# Stopping a Level Change

A level change initiated using any of the functions referenced in [Section 16.5.1](changing_level.md#id_82d61a0b-7d29-492d-b406-ed9f96a5728f) can be halted using the function **eCLD\_LevelControlCommandStopCommandSend\(\)** or**eCLD\_LevelControlCommandStopWithOnOffCommandSend\(\)**.
