# Initialization

The function         **eCLD\_GroupsCreateGroups\(\)** is used to create an instance of the Groups cluster. The function is called by the initialization function for the host device.

A local endpoint can be added to a group on the local node using the function **eCLD\_GroupsAdd\(\)**. If the group does not exist, the function creates it. Therefore, this is a way of creating a local group.
