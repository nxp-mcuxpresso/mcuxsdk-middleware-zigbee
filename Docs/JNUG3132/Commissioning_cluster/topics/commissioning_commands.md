# Commissioning Commands

A number of commissioning commands are provided to allow a Commissioning cluster client to remotely request actions relating to the Start-up Parameters attribute set \(see [Section 43.2.1](start-up_parameters_tscld_startupparameters.md#id_d22b5600-7fda-403a-90c7-d433548a4983)\) on a cluster server. This includes initiating a device restart from the current Start-up Parameter values, as well as the management of these attributes.
