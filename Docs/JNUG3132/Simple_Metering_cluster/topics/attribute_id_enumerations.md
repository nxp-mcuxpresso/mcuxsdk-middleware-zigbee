**Note:** Some of the following enumerations correspond to attributes that are not certifiable in SE 1.1.1 \(07-5356-17\) or earlier and are for future use \(as indicated in the attribute descriptions in [Section 42.2](simple_metering_cluster_structure_and_attributes.md#id_1c898ead-e5b8-46b9-9117-d5b84c56d269)\).
