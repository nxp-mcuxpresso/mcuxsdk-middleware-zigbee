# Measurement and Sensing

The Measurement and Sensing clusters implemented by NXP are listed and outlined in the table below. These clusters are detailed in ‘[Part IV: Measurement and Sensing](../../divider4/topics/part_iv__measurement_and_sensing_clusters.md#id_7058be3f-7787-4665-a15f-f1328b6468c4)Clusters’ of this manual.

|**Cluster**|**Cluster ID**|**Description**|
|-----------|--------------|---------------|
|Illuminance Measurement|0x0400|The Illuminance Measurement cluster provides an interface to an illuminance measuring device, allowing the configuration of measuring and the reporting of measurements. This cluster is detailed in [Chapter 23](../../Illuminance_Measurement_cluster/topics/illuminance_measurement_cluster.md#id_23d80ff4-b719-417c-a0b7-1deda4fccd23).|
|Illuminance Level Sensing|0x0401|The Illuminance Level Sensing cluster provides an interface to light-level sensing functionality. This cluster is detailed in [Chapter 24](../../Illuminance_Level_Sensing_cluster/topics/illuminance_level_sensing_cluster.md#id_cc86a2b6-4b7b-4b9f-9ae6-2eea90d8395c).|
|Temperature Measurement|0x0402|The Temperature Measurement cluster provides an interface to a temperature measuring device, allowing the configuration of measuring and the reporting of measurements. This cluster is detailed in [Chapter 25](../../Temp_Measurement_cluster/topics/temperature_measurement_cluster.md#id_8ec2ebb1-d509-4d90-9b6b-39b86e2ea079).|
|Pressure Measurement|0x0403|The Pressure Measurement cluster provides an inter-face to a pressure measuring device, allowing the configuration of measuring and the reporting of measurements. This cluster is detailed in [Chapter 26](../../pressure_measurement_cluster/topics/pressure_measurement_cluster.md#id_05e9c48c-8b3a-4fee-b387-dcf0af68767e).|
|Flow Measurement|0x0404|The Flow Measurement cluster provides an interface to a flow measuring device for a fluid, allowing the configuration of measuring and the reporting of measurements. This cluster is detailed in [Chapter 27](../../flow_measurement_cluster/topics/flow_measurement_cluster.md#id_683eceab-8458-4fb9-8b0d-3b2c964dea68).|
|Relative Humidity Measurement|0x0405|The Relative Humidity Measurement cluster provides an interface to a humidity measuring device, allowing the configuration of relative humidity measuring and the reporting of measurements. This cluster is detailed in [Chapter 28](../../Rel_Hum_Measurement_cluster/topics/relative_humidity_measurement_cluster.md#id_ffba8e89-b182-4189-8ef2-6cec8f1315f6).|
|Occupancy Sensing|0x0406|The Occupancy Sensing cluster provides an interface to an occupancy sensor, allowing the configuration of sensing and the reporting of status. This cluster is detailed in [Chapter 29](../../Occupancy_Sensing_cluster/topics/occupancy_sensing_cluster.md#id_3430306a-a092-4cca-9480-aef30e937d88).|
|Electrical Measurement|0x0B04|The Electrical Measurement cluster provides an interface for obtaining electrical measurements from a device. This cluster is detailed in [Chapter 30](../../electrical_measurement_cluster/topics/electrical_measurement_cluster.md#id_a3ab2726-c85a-4d96-a8e1-3827b51a38c4).|
