# Appliances

The Appliances clusters implemented by NXP are listed and outlined in the table below. These clusters are detailed in ‘[Part XI: Appliances Clusters](../../divider11/topics/part_xi__appliances_clusters.md#id_2d45847d-6dac-4c62-8b25-68f4bdfae853)’ of this manual.

|**Cluster**|**Cluster ID**|**Description**|
|-----------|--------------|---------------|
|Appliance Control|0x001B|The Appliance Control cluster provides an interface for remotely controlling appliances in the home. This cluster is detailed in [Chapter 45](../../appliance_control_cluster/topics/appliance_control_cluster.md#id_de2e147c-a77e-440d-a30d-837ca20be885).|
|Appliance Identification|0x0B00|The Appliance Identification cluster provides an interface for obtaining and setting basic appliance information. This cluster is detailed in [Chapter 46](../../appliance_identification_cluster/topics/appliance_identification_cluster.md#id_737c20ee-5404-4881-b6c3-96c9beed2ab0).|
|Appliance Events and Alerts|0x0B02|The Appliance Events and Alerts cluster provides an interface for the notification of significant events and alert situations. This cluster is detailed in [Chapter 47](../../appliance_events_alerts_cluster/topics/appliance_events_and_alerts_cluster.md#id_ae2c3d72-955f-41d0-af32-989413bbda86).|
|Appliance Statistics|0x0B03|The Appliance Statistics cluster provides an interface for supplying statistical information about an appliance. This cluster is detailed in [Chapter 48](../../appliance_statistics_cluster/topics/appliance_statistics_cluster.md#id_92cb2bef-0b84-43c3-a448-b14026a3aa7d).|
