# General

The General clusters implemented by NXP are listed and outlined in the table below. These clusters are detailed in ‘[Part III: General Clusters](../../divider3/topics/part_iii__general_clusters.md#id_76b12229-9cb5-4754-9bc6-40cdd4319e58)’ of this manual.

|**Cluster**|**Cluster ID**|**Description**|
|-----------|--------------|---------------|
|Basic|0x0000|The Basic cluster contains the basic properties of a ZigBee device for example, software and hardware versions. The Basic cluster allows the setting of user-defined properties such as location. This cluster is detailed in [Chapter 8](../../Basic_cluster/topics/basic_cluster.md#id_607c1094-a342-4552-95ff-4f0eb2fb78c2).|
|Power Configuration|0x0001|The Power Configuration cluster allows users to determine the power source details of a device and helps configure the under/over-voltage alarms. This cluster is detailed in [Chapter 9](../../Power_Configuration_cluster/topics/power_configuration_cluster.md#id_55965dfd-7aa3-46fb-99ed-fedfeec0f9a2).|
|Device Temperature Configuration|0x0002|The Device Temperature Configuration cluster allows information about the internal temperature of a device to be obtained and under/over-temperature alarms to be configured. This cluster is detailed in [Chapter 10](../../Device_Temp_Configuration_cluster/topics/device_temperature_configuration_cluster.md#id_d5871e15-4d16-42aa-b996-a753a1e075bb).|
|Identify|0x0003|The Identify cluster allows a ZigBee device to make itself known visually \(for example, by flashing a light\) to an observer, such as a network installer. This cluster is detailed in [Chapter 11](../../Identify_cluster/topics/identify_cluster.md#id_8d39ccb7-5ec3-439b-af2c-8b6105768b6d).|
|Groups|0x0004|The Groups cluster allows the management of the Group table concerned with group addressing - that is, the targeting of multiple endpoints using a single address. This cluster is detailed in [Chapter 12](../../Groups_cluster/topics/groups_cluster.md#id_b6af3456-b2dc-4439-8085-c09909bffbe2).|
|Scenes|0x0005|The Scenes cluster allows the management of pre-defined sets of cluster attribute values called scenes, where a scene can be stored, retrieved, and applied to put the system into a pre-determined state. This cluster is detailed in [Chapter 13](../../Scenes_cluster/topics/scenes_cluster.md#id_6e49ba6c-88c2-4dbb-a986-2965b3fc17f7).|
|On/Off|0x0006|The On/Off cluster allows a device to be put into the ‘on’ and ‘off’ states, or toggled between the two states. This cluster is detailed in [Chapter 14](../../OnOff_cluster/topics/onoff_cluster.md#id_95380f68-4a55-4dd0-814d-ba1e49f7f592).|
|On/Off Switch Configuration|0x0007|The On/Off Switch Configuration cluster allows the switch type on a device to be defined, as well as the commands to be generated when the switch is moved between its two states. This cluster is detailed in [Chapter 15](../../OnOff_Switch_Config_cluster/topics/onoff_switch_configuration_cluster.md#id_cb71d38c-0367-4f03-9a82-8a92202ae39d).|
|Level Control|0x0008|The Level Control cluster allows control of the level of a physical quantity \(for example, heat output\) on a device. This cluster is detailed in [Chapter 16](../../Level_Control_cluster/topics/level_control_cluster.md#id_492efae6-d88d-4203-be53-0039b6fe8f2d).|
|Alarms|0x0009|The Alarms cluster is used for sending alarm notifications and the general configuration of alarms for all other clusters on the ZigBee device \(individual alarm conditions are set in the corresponding clusters\). This cluster is detailed in [Chapter 17](../../Alarms_cluster/topics/alarms_cluster.md#id_709bda96-0108-4916-8d58-eab1f23dd3b0).|
|Time|0x000A|The Time cluster provides an interface to a real-time clock on a ZigBee device, allowing the clock time to be read and written in order to synchronize the clock to a time standard. This is the number of seconds since 0 hrs 0 mins 0 secs on 1st January 2000 UTC \(Coordinated Universal Time\). This cluster includes functionality for local time-zone and daylight saving time. This cluster is detailed in [Chapter 18](../../Time_cluster/topics/time_cluster_and_zcl_time.md#id_4d63ad38-ffbb-4bd9-a794-b4e7b3ba2d67).|
|Analogue Input \(Basic\)|0x000C|The Analogue Input \(Basic\) cluster provides an interface for accessing an analog measurement. This cluster is detailed in [Section 19.1](../../Binary_Input_Basic_cluster/topics/analogue_input_basic.md#id_04f45336-cc01-40ef-9eee-de62b42847a3).|
|Analogue Output \(Basic\)|0x000D|The Analogue Output \(Basic\) cluster provides an interface for setting the value of an analog output. This cluster is detailed in [Section 19.2](../../Binary_Input_Basic_cluster/topics/analogue_output_basic.md#id_7498eb47-6996-4a8f-97a4-6322317a2c93).|
|Binary Input \(Basic\)|0x000F|The Binary Input \(Basic\) cluster provides an interface for accessing a binary \(two-state\) measurement. This cluster is detailed in [Section 19.3](../../Binary_Input_Basic_cluster/topics/binary_input_basic_cluster.md#id_3c6faea1-c00e-4b85-b298-53fb836b3df2).|
|Binary Output \(Basic\)|0x0010|The Binary Output \(Basic\) cluster provides an inter-face for setting the state of a binary \(two-state\) output. This cluster is detailed in [Section 19.4](../../Binary_Input_Basic_cluster/topics/binary_output_basic.md#id_7a4f373c-c0e6-480d-a560-3639b7f1fac7).|
|Multistate Input \(Basic\)|0x0012|The Multistate Input \(Basic\) cluster provides an interface for accessing a multistate measurement \(that can take one of a set of fixed states\). This cluster is detailed in [Section 19.5](../../Binary_Input_Basic_cluster/topics/multistate_input_basic.md#id_e45184f3-7860-41c6-a8c1-07f7d443adf3).|
|Multistate Output \(Basic\)|0x0013|The Multistate Output \(Basic\) cluster provides an interface for setting the value of a multistate output \(that can take one of a set of fixed states\). This cluster is detailed in [Section 19.6](../../Binary_Input_Basic_cluster/topics/multistate_output_basic.md#id_2639d965-9b14-466c-ad23-bcbb5dad1612).|
|Poll Control|0x0020|The Poll Control cluster provides an interface for remotely controlling the rate at which a ZigBee End Device polls its parent for data. This cluster is detailed in [Chapter 20](../../poll_control_cluster/topics/poll_control_cluster.md#id_df60ef89-7db8-4ee3-8585-efa4cbd3f0cc).|
|Power Profile|0x001A|The Power Profile cluster provides an interface between a home appliance \(for example, a washing machine\) and the controller of an energy management system. This cluster is detailed in [Chapter 21](../../power_profile_cluster/topics/power_profile_cluster.md#id_c10ea2ad-2bfe-4216-bcaa-7e0a4bf42864).|
|Diagnostics|0x0B05|The Diagnostics cluster allows the operation of the ZigBee PRO stack to be followed over time. This cluster is detailed in [Chapter 22](../../Diagnostics_cluster/topics/diagnostics_cluster.md#id_a1a99033-70dd-400b-8749-bc4db774b38b).|
