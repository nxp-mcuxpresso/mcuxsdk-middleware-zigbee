# Applying a Scene

An existing scene can be applied on the local node using the function **eCLD\_ScenesRecall\(\)**. This function reads the stored attribute values for the specified scene from the local Scene table and implements them on the device. The values of any attributes that are not included in the scene remain unchanged.
