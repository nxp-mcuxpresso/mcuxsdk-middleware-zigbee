# Attributes for default reporting

The following attributes of the Appliance Control cluster can be selected for default reporting:

```
u16StartTime 
u16FinishTime

```

-   `u16RemainingTime`


Attribute reporting \(including default reporting\) is described in [Appendix B.](../../appendix/topics/attribute_reporting.md#id_aa644443-d8c4-48c6-aeb2-7d1c62cd5c77) Enabling reports for these attributes is described in [Appendix B.3.6](../../appendix/topics/configuring_default_reporting_on_server.md#id_0ee5c3fa-71ff-4e90-8062-e0a7201c793e).
