# u32ZCL\_GetUTCTime

```
uint32 u32ZCL_GetUTCTime(void);

```

## Description 

This function obtains the current time \(UTC\) that is stored in the ZCL \(‘ZCL time’\).

## Parameters 

-   None

## Returns 

-   The current time \(UTC\), in seconds, obtained from the ZCL
