# vZCL\_ClearTimeHasBeenSynchronised

```
void vZCL_ClearTimeHasBeenSynchronised(void);

```

## Description 

This function is used to notify the ZCL that the local ZCL time may no longer be accurate.

## Parameters 

-   None

## Returns 

-   None
