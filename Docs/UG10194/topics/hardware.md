# Hardware

NXP enables the development of ZigBee 3.x applications by providing supported hardware kits. The following boards provide a platform for running the Zigbee applications:

- K32W148-EVK board
- FRDM-MCXW71 board
- MCX-W72-EVK board
- FRDM-RW612 board
- RD-RW612-BGA board
