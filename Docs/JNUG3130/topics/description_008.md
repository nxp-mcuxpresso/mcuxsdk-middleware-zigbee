# Description

This function can be used on the Trust Centre to obtain the 64-bit IEEE \(MAC\) address of the node for which a link key has been persistently stored in the specified location in devices Flash memory. The location is specified as the number of the array element for the node - see the description of [ZPS\_vTcInitFlash](zps_vtcinitflash.md).
