# ZDP structures

This section describes the structures used by the ZigBee Device Profile \(ZDP\) API. Three sets of structures are presented:

-   Structures used to represent the descriptors that reside on a node - see [Section](descriptor_structures_001.md)[9.2.1](descriptor_structures_001.md)
-   Structures used to issue requests using the ZDP functions - see [Section 9.2.2](zdp_request_structures.md)
-   Structures used to receive responses to the ZDP requests - see [Section 9.2.3](zdp_response_structures.md)
