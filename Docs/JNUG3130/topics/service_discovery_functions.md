# Service Discovery functions

The ZDP Service Discovery functions are concerned with obtaining information about the nature and capabilities of a network node.

The functions are listed below.

1.  [ZPS\_eAplZdpNodeDescRequest](zps_eaplzdpnodedescrequest.md)
2.  [ZPS\_eAplZdpPowerDescRequest](zps_eaplzdppowerdescrequest.md)
3.  [ZPS\_eAplZdpSimpleDescRequest](zps_eaplzdpsimpledescrequest.md)
4.  [ZPS\_eAplZdpExtendedSimpleDescRequest](zps_eaplzdpextendedsimpledescrequest.md)
5.  [ZPS\_eAplZdpComplexDescRequest](zps_eaplzdpcomplexdescrequest.md)
6.  [ZPS\_eAplZdpUserDescRequest](zps_eaplzdpuserdescrequest.md)
7.  [ZPS\_eAplZdpMatchDescRequest](zps_eaplzdpmatchdescrequest.md)
8.  [ZPS\_eAplZdpActiveEpRequest](zps_eaplzdpactiveeprequest.md)
9.  [ZPS\_eAplZdpExtendedActiveEpRequest](zps_eaplzdpextendedactiveeprequest.md)
10. [ZPS\_eAplZdpUserDescSetRequest](zps_eaplzdpuserdescsetrequest.md)
11. [ZPS\_eAplZdpSystemServerDiscoveryRequest](zps_eaplzdpsystemserverdiscoveryrequest.md)
12. [ZPS\_eAplZdpDiscoveryCacheRequest](zps_eaplzdpdiscoverycacherequest.md)
13. [ZPS\_eAplZdpDiscoveryStoreRequest](zps_eaplzdpdiscoverystorerequest.md)
14. [ZPS\_eAplZdpNodeDescStoreRequest](zps_eaplzdpnodedescstorerequest.md)
15. [ZPS\_eAplZdpPowerDescStoreRequest](zps_eaplzdppowerdescstorerequest.md)
16. [ZPS\_eAplZdpSimpleDescStoreRequest](zps_eaplzdpsimpledescstorerequest.md)
17. [ZPS\_eAplZdpActiveEpStoreRequest](zps_eaplzdpactiveepstorerequest.md)
18. [ZPS\_eAplZdpFindNodeCacheRequest](zps_eaplzdpfindnodecacherequest.md)
19. [ZPS\_eAplZdpRemoveNodeCacheRequest](zps_eaplzdpremovenodecacherequest.md)
