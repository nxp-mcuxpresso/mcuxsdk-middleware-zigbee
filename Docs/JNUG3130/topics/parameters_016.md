# Parameters

-   *__u8Endpoint__:* Endpoint number \(on local node\)

-   *__u16ClusterId__:* Cluster ID

-   *__bOutput__:* Type of cluster \(output or input\), one of:

    -   TRUE: Output cluster

    -   FALSE: Input cluster

-   *__bDiscoverable__:* Discoverable state to set, one of:

    -   TRUE: Discoverable

    -   FALSE: Not discoverable
