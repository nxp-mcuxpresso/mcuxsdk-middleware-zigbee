# Setting the radio channel for the network

The choice of 2.4-GHz band channel for the network is pre-configured via the the ZPS Configuration Editor \(see [Section 13.4.3](setting_coordinator_properties.md)\). It is either a fixed channel in the range 11-26 or a set of channels from which the best channel is selected by the Coordinator. In the latter case, the Coordinator performs an energy scan of the possible channels and chooses the quietest channel.
