# Return/Status Codes

The return/status codes that can result from ZigBee PRO API function calls are divided into the following groups:

-   ZDP codes - see [Section 11.2.1](zdp_codes.md)
-   APS codes - see [Section 11.2.2](aps_codes.md)
-   NWK codes - see [Section 11.2.3](nwk_codes.md)
-   MAC codes - see [Section 11.2.4](mac_codes.md)
-   Extended error codes - see [Section 11.2.5](extended_error_codes.md)
