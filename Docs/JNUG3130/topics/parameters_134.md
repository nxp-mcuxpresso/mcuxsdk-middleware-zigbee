# Parameters

-   *u8KeyType* Type of key to request:
    -   2 - application link key
    -   4 - Trust Centre Link Key \(TCLK\)
    -   All other values reserved

-   *u64IeeePartnerAddr* IEEE/MAC address of partner node \(for application link key\)
