# Description

This function can be used on a Router node to introduce the node into a distributed security network \(see [Section 6.10.2](distributed_security_networks.md)\). The function must be called on the Router node that creates the distributed security network, therefore, the first node of the new network.

Subsequent Router nodes may be introduced using this function, but could be introduced using other commissioning methods, such as Touchlink.
