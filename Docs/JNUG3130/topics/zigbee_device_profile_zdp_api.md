# ZigBee Device Profile \(ZDP\) API

The chapter describes the resources of the ZigBee Device Profile \(ZDP\) API. This API is concerned with sending network requests \(for example, binding requests\) and receiving responses. The API is defined in the header file **zps\_apl\_zdp.h**.

In this chapter:

-   [Section 9.1](zdp_api_functions.md) details the ZDP API functions.
-   [Section 9.2](zdp_structures.md) details the ZDP API structures.
-   [Section 9.3](broadcast_addresses.md) describes the broadcast options when sending requests using the ZDP API functions.
