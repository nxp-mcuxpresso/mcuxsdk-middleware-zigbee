# Description

This function can be used on an End Device node to introduce the node into a distributed security network \(see [Section 6.10.2](distributed_security_networks.md)\). This network must have already been created by a Router using the **ZPS\_eAplFormDistributedNetworkRouter\(\)** function. End Device nodes may be introduced into the network in this way or using other commissioning methods, such as Touchlink.
