-   Features and concepts related to message routing. See Section 3.5, \([Network routing](network_routing.md)\)
-   Features and concepts related to exchanging messages. See Section 3.6, \([Network communications](network_communications.md)\)
-   A detailed view of the ZigBee PRO software architecture. See Section 3.7, \([Detailed architecture](detailed_architecture.md)\)
