# Profile definition parameters

**Profile definition parameters**

|**Parameter Name**|**Description**|**Default Value**|**Range**|
|--|--|--|--|
|*Profile Id*|The application profile identifier. This is assigned by the ZigBee Alliance for a public profile.| |16 bits<br>\(Value 0 is reserved for the ZDP, 0xFFFF is wildcard profile\)|
|*Name*|Textual name for the profile. This is used as a prefix for generated macro definitions in **zps\_gen.h**.| |Valid C identifier. \(“ZDP” is reserved for the ZigBee Device Profile\)|
