# Network Management Services functions

The ZDP Network Management Services functions are concerned with requests for network operations to be implemented remotely.

The functions are listed below.

1.  [ZPS\_eAplZdpMgmtNwkDiscRequest](zps_eaplzdpmgmtnwkdiscrequest.md)
2.  [ZPS\_eAplZdpMgmtLqiRequest](zps_eaplzdpmgmtlqirequest.md)
3.  [ZPS\_eAplZdpMgmtRtgRequest](zps_eaplzdpmgmtrtgrequest.md)
4.  [ZPS\_eAplZdpMgmtBindRequest](zps_eaplzdpmgmtbindrequest.md)
5.  [ZPS\_eAplZdpMgmtLeaveRequest](zps_eaplzdpmgmtleaverequest.md)
6.  [ZPS\_eAplZdpMgmtDirectJoinRequest](zps_eaplzdpmgmtdirectjoinrequest.md)
7.  [ZPS\_eAplZdpMgmtPermitJoiningRequest](zps_eaplzdpmgmtpermitjoiningrequest.md)
8.  [ZPS\_eAplZdpMgmtCacheRequest](zps_eaplzdpmgmtcacherequest.md)
9.  [ZPS\_eAplZdpMgmtNwkUpdateRequest](zps_eaplzdpmgmtnwkupdaterequest.md)
10. [ZPS\_eAplZdpParentAnnceReq](zps_eaplzdpparentanncereq.md)

**Note:** Some of these functions cannot be used to send requests to nodes that run the NXP ZigBee PRO stack. They are supplied in the ZDP API in order to facilitate interoperability with nodes based on non-NXP software which supports the corresponding requests.
