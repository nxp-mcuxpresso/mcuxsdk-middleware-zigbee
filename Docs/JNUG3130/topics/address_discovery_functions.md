# Address discovery functions

The ZDP Address Discovery functions are concerned with obtaining addresses of nodes in the network.

The functions are listed below:

1.  [ZPS\_eAplZdpNwkAddrRequest](zps_eaplzdpnwkaddrrequest.md)
2.  [ZPS\_eAplZdpIEEEAddrRequest](zps_eaplzdpieeeaddrrequest.md)
3.  [ZPS\_eAplZdpDeviceAnnceRequest](zps_eaplzdpdeviceanncerequest.md)

**Note:** Further addressing functions are provided in the ZDO API and are described in [Section 7.1.3](addressing_functions.md).
