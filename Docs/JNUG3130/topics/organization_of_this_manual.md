# Organization of this manual

This manual is divided into four parts:

-   Part I: Concept and Operational Information consists of six chapters:
    -   **Chapter 1:** [Preface](preface.md) provides an overview of the document contents, conventions, support resources, and compatibility information.
    -   **Chapter 2:** [ZigBee overview](zigbee_overview.md) introduces the ZigBee 3.0 wireless network protocol.
    -   **Chapter 3:** [ZigBee PRO architecture and operation](zigbee_pro_architecture_and_operation.md) describes the architecture and features of ZigBee 3.0.
    -   **Chapter 4:** [ZigBee Stack Software](zigbee_stack_software.md) introduces the NXP ZigBee PRO stack software.
    -   **Chapter 5:** [Application development overview](application_development_overview.md) provides an overview of the ZigBee 3.0 application development environment and process.
    -   **Chapter 6:** [Application coding with ZigBee PRO APIs](application_coding_with_zigbee_pro_apis.md) describes how to perform common wireless network operations using the functions of the NXP ZigBee 3.0 APIs.
-   Part II: Reference Information consists of six chapters:
    -   **Chapter 7:** [ZigBee Device Objects \(ZDO\) API](zigbee_device_objects_zdo_api.md) details the functions and associated resources of the ZigBee Device Objects \(ZDO\) API.
    -   **Chapter 8:** [Application Framework \(AF\) API](application_framework_af_api.md) details the functions and associated resources of the Application Framework \(AF\) API.
    -   **Chapter 9:** [ZigBee Device Profile \(ZDP\) API](zigbee_device_profile_zdp_api.md) details the functions and associated resources of the ZigBee Device Profile \(ZDP\) API.
    -   **Chapter 10:** [General ZPS Resources](general_zps_resources.md) details the general functions and associated resources provided with the NXP ZigBee PRO stack.
    -   **Chapter 11:** [Event and Status Codes](event_and_status_codes.md) details the stack events and the return/status codes used by the ZigBee PRO APIs.
    -   **Chapter 12:** [ZigBee network parameters](zigbee_network_parameters.md) details the ZigBee network parameters.
-   Part III: Network Configuration consists of one chapter:
    -   **Chapter 13:** [ZPS Configuration Editor](zps_configuration_editor.md) describes how to use the ZPS Configuration Editor.
-   Part IV: contains various ancillary information that include the following:
    -   **__Appendix A__:** [Appendix A: Handling stack events](handling_stack_events.md): a description of the handling of ZigBee PRO stack events.
    -   **__Appendix B__:** [Appendix B: Application design notes](application_design_notes.md): a set of design application notes.
    -   **__Appendix C__:** [Appendix C: Implementation of frame counters](implementation_of_frame_counters.md): a description of frame counters.
    -   **Appendix D:** [Appendix D: storing applications in device flash memory](storing_applications_in_device_flash_memory.md): a description of application storage in Flash memory.
    -   **Appendix E:** a glossary of terms used in ZigBee 3.0 networks.
    -   **Appendix F:** Revision History for the document.
