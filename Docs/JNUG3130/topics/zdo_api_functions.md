# ZDO API functions

The ZDO API functions are divided into the following categories:

1.  **Network Deployment**functions, described in [Network deployment functions](network_deployment_functions.md).
2.  **Security**functions, described in [Security functions](security_functions.md).
3.  **Addressing**functions, described in [Addressing functions](addressing_functions.md).
4.  **Routing**functions, described in [Routing functions](routing_functions.md).
5.  **Object Handle**functions, described in [Object Handle functions](object_handle_functions.md).
6.  **Optional Cluster**function, described in [Optional Cluster function](optional_cluster_function.md).
