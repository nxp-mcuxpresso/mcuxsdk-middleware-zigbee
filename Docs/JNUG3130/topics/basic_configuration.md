# Basic configuration

The function **zps\_vAplAfEnableMcpsFilter\(\)** allows the stack’s packet filtering to be enabled and the link cost threshold to be adjusted \(from the default value of 5\). This function is detailed in [Section 8.1.1](initialization_functions.md). If required, it can be called at any time after **zps\_eAplAfInit\(\)**.
