# Parameters

-   *psFlashInfoSet* Pointer to a structure containing information about the Flash memory sector to be used to store the link keys for the network nodes \(see [Section 8.2.3.8](zps_tsafflashinfoset.md)\)
-   *psTclkStruct* Pointer to a structure in RAM that is used to hold information about the storage of one link key in Flash memory \(see [Section 8.2.3.9](zps_tclkdescriptorentry.md)\)
