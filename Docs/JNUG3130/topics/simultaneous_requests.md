# Simultaneous requests

This refers to the maximum number of destinations for a bound data transfer. The value set must be less than or equal to the value of the ZigBee network parameter *Maximum Number of Simultaneous Data Requests*or *Maximum Number of Simultaneous Data Requests with Acks*, described in [Section 11.7](advanced_device_parameters.md).
