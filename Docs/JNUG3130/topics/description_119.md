# Description

This function can be used to create an application record of the Extended PAN ID \(EPID\) of the network to which the local device belongs.

-   The only use of this function for a Coordinator is described in [Section 6.1.1](starting_the_coordinator.md).
-   The function should only be called on a Router or End Device in the manner described in [Section 6.1.2](starting_routers_and_end_devices.md).
