# To add a profile

**_Step 1_** Right-click on **ZigBee PRO Wireless Network** and select **New Child &gt; Profile** from the drop-down menu. This inserts a profile with no child elements.

**_Step 2_** Edit the properties in the **Properties** tab to set **Name** and **Id** for the new profile.
