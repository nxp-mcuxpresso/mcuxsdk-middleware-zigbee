# Parameters

-   **_u8Endpoint_**: Endpoint number \(on local node\)
-   **\*_pbEnabled_**: Pointer to location to receive endpoint state. The returned state is one of:
    -   TRUE: endpoint enabled
    -   FALSE: endpoint disabled
